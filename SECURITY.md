# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository. Do not open a public issue.

Include the affected version, how to reproduce, and the impact you see. You can expect
an acknowledgment within a few days. Please give us reasonable time to release a fix
before public disclosure.

## Supported versions

This project is pre-1.0. Security fixes go into the latest release only.

## Scope

In scope: the agent, server, assessment worker, container image and deployment
manifests in this repository. Findings *produced by* the tool (for example a CVE in a
package it reports) are not vulnerabilities in this project.

See the [security model](README.md#security-model) for the design assumptions.
